## How to use this inventory

1. Treat these files as the preserved intake record.
2. Create normalised catalogue entries in a separate pass.
3. Keep the original section and category labels alongside any normalised labels.
4. Mark possible duplicates and variants as relationships for review; do not delete them at intake.
5. Verify every named method, model, software package and citation before publishing a technical claim.
6. Where the source itself says an item is from memory and needs verification, treat it as an explicit research flag.

## Important distinction

The compendium is broad coverage, not proof that every listed item is an algorithm in the strict sense. It includes operations, data structures, models, software systems, indices, metrics, standards, workflows and applied methods. Catalogue records should preserve these distinctions rather than forcing every entry into one type.

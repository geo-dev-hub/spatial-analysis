# Exercise: location set covering

1. Solve the visual-lab example at 8, 10 and 15 minutes.
2. Record the minimum number of facilities at each threshold.
3. Remove one candidate site and check whether all demand can still be covered.
4. Compare set covering with MCLP using the same threshold and demand matrix.
5. Identify a case where every demand point is technically covered but facility capacity makes the plan infeasible operationally.
6. Propose a weighted opening-cost objective and explain how it differs from minimizing facility count.

Record the cost unit, threshold rationale, candidate set, selected facilities, assignments, infeasible rows (if any) and limitations.

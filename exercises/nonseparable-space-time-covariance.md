# Exercises: nonseparable space-time covariance

Read the [method lesson](../methods/nonseparable-space-time-covariance.md) and run the lab notebook.

1. Predict how covariance changes with temporal lag for positive beta. What changes when beta is zero?
2. Compare a separable product with the Gneiting construction at two spatial separations and three temporal lags.
3. Build a matrix for at least six irregularly sampled observations. Check symmetry and eigenvalues. Explain why this is not a universal proof.
4. Change alpha, beta, spatial scale and temporal scale one at a time.
5. Explain why replacing Euclidean distance with river-network distance requires a separate validity result.

Submit parameter values, one space-time plot, one matrix diagnostic and a short account of assumptions. A plot alone does not establish covariance validity.
